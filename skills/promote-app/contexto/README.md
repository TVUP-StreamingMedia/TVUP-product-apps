# Contexto de la app

Esta carpeta describe **qué es y cómo está hecha esta app**. El agente (Claude Code o AI Studio)
la lee antes de trabajar, así que lo que pongas aquí lo sabrá en cada sesión.

- La actualiza quien cambia la app, en el mismo PR que el cambio.
- Describe la app; **nunca cambia las reglas**. Las reglas están en `CLAUDE.md` / `GEMINI.md`
  y, si algo de aquí las contradice, ganan las reglas.
- Cada fichero, por debajo de unas 150 líneas. Si crece, resume lo antiguo.
- Nada de secretos, datos personales ni datos reales de clientes.
